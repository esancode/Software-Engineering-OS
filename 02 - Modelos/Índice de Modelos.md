# Índice de Modelos

> Catálogo completo de modelos prontos para copiar, colar e preencher.

---

## Como usar os modelos

1. Navegue até a pasta do modelo desejado
2. Abra o arquivo `.md`
3. Selecione tudo (`Ctrl+A`) → Copie (`Ctrl+C`)
4. Na pasta do seu projeto (`05 - Projetos/SeuProjeto/...`), crie nova nota
5. Cole (`Ctrl+V`) e preencha os campos `[Preencher aqui]`

> [!tip]
> Mantenha os modelos **intocados** na pasta `02 - Modelos/`. Copie para o projeto antes de editar.

## Convenções dos Modelos

- **Campos a preencher:** `[Preencher aqui]` ou `---` em tabelas
- **Checklists:** `- [ ]` para marcar conforme preenche
- **Exemplos:** Incluídos em itálico ou blocos de código
- **Seções condicionais:** Marcadas com `⚠️ CONDICIONAL` — só use se aplicar ao seu projeto
- **Links internos:** Apontam para etapas e guias relacionados

---

## Criando seus próprios modelos

Se precisar de um modelo que não existe:

1. Copie o modelo mais similar
2. Adapte para sua necessidade
3. Salve na categoria apropriada em `02 - Modelos/`
4. Atualize este índice
5. Referencie nas etapas relevantes
