# Início — Software Engineering OS

> Bem-vindo ao seu manual de desenvolvimento de software.

---

## Para que serve este manual

Este manual ajuda você a **desenvolver software de ponta a ponta** de forma organizada, consciente e profissional, usando **Vibe Coding** (desenvolvimento assistido por IA com Claude Code).

Ele responde às perguntas essenciais em cada momento:
- **O que preciso fazer agora?**
- **Por que preciso fazer isso?**
- **Em qual ordem?**
- **O que posso delegar à IA?**
- **O que preciso decidir eu?**
- **Como verifico se está certo?**
- **Quando posso avançar?**

## Como o manual está organizado

### 01 - Manual de Desenvolvimento
As **17 etapas numeradas** do ciclo de vida do software, cada uma com:
- Objetivo claro
- Ações em ordem
- Responsabilidades (Usuário / IA / Validação)
- Documentos necessários
- Checklist de execução
- Critérios de conclusão
- Como lidar com bloqueios
- Link para a próxima etapa

Modelos prontos para **copiar, colar e preencher** — agrupados por fase:

## Papéis nas atividades

| Ícone | Papel | O que significa |
|-------|-------|-----------------|
| 👤 | **USUÁRIO** | Você decide, aprova, escolhe |
| 🤖 | **IA** | Delegue ao Claude Code |
| ✅ | **VALIDAÇÃO** | Verifique, teste, confira |

Em cada etapa, as atividades são marcadas com estes indicadores.

---

## Princípio: não avance sem critérios

> [!warning]
> **Não considere uma etapa concluída apenas porque a IA disse que terminou.**
>
> Cada etapa tem **critérios objetivos de conclusão**. Você deve verificar as evidências antes de aprovar e avançar.

## Seu primeiro passo

Se esta é sua primeira vez aqui:

1. Leia **[[Como Usar Este Manual]]** (5 min)
2. Quando tiver uma ideia de projeto, vá para **[[Iniciar Novo Projeto]]**
3. Siga as etapas em ordem — cada uma aponta para a próxima
